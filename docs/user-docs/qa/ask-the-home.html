QA: Ask the home with the local Basic Agent

Part of: Ask the home with the local Basic Agent

Purpose

Verify that the local Basic Agent answers current and recent-history questions through the authorized gateway without effect authority and with visible evidence references.

Preconditions

  • Start PWCE with npm run dev.
  • Open http://127.0.0.1:4173/.
  • Use seeded state or a running local Home Assistant instance with an accepted observation.

Acceptance Criteria

Testing Instructions

  1. Open the Studio page and find “Ask the home”.

    The panel shows “Local read-only Agent” and “Offline capable”.

  2. Ask “What is the light state?”.

    The response includes the current value, “Mode: current”, and an evidence reference when state is known.

  3. Ask “Show the recent history”.

    The response includes “Mode: history” and a bounded result.

  4. Remove or avoid the accepted observation and ask again.

    The Agent says it does not have an accepted observation and does not invent a value.

Edge cases

  • Question longer than 512 characters → bounded validation error.
  • Site outside the Agent’s configured site scope → scope denial.
  • Live effects → unavailable because the Basic Agent has no effect authority.
