Ask the home with the local Basic Agent

Use the local read-only Agent to ask what PWCE currently knows about the development light and to inspect its recent history.

Before you start

  • Start PWCE with npm run dev.
  • Open http://127.0.0.1:4173/.
  • Load a Home Assistant observation or use seeded development data.

Walkthrough

  1. Open the “Ask the home” panel.

    You should see “Local read-only Agent” and “Offline capable”.

  2. Enter “What is the light state?” and select Ask Agent.

    The Agent gives a current answer, identifies the retrieval mode, and shows supporting evidence when available.

  3. Ask “Show the recent history”.

    The Agent reports the number of accepted observations and shows their actual supporting observation references.

History evidence references identify the observations returned by the Gateway. You can use them for an authorized evidence lookup; a reference does not grant access to another site.

What this Agent does not do

This development Agent performs deterministic read-only retrieval through the authenticated PWCE gateway. It does not infer facts beyond gateway results, call Home Assistant services, or approve actions. A missing observation remains unknown.

Tips & troubleshooting

  • No accepted observation: the answer remains explicitly unknown.
  • Offline: the local Agent continues to use local PWCE state when it is available.
  • Question rejected: keep the question between 1 and 512 characters.
