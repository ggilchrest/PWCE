Recover a missing permission reply

An integration can find the original action permission even when its reply was lost.

What changed

A read-only lookup uses the request details saved before sending. It returns the original record and action number without creating permission or sending a command. An expired permission keeps its original deadline.

Why it matters

A lost reply no longer requires guessing the action number. An unknown result remains uncertain, and current access still controls what can be read.

What to test

  • Missing permission reply checks — use the synthetic tests to verify original evidence, unchanged target calls, expired permission and scope refusal.

Where to read more

Screenshots updated

None; Studio controls and layout are unchanged.

Known issues / follow-ups

Lifestream will adopt this lookup next. Saved runtime activation and full PWCE authority-context restoration remain separate work.
