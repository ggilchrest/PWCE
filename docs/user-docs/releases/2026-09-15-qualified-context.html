Qualified context and historical evidence

Prepared context now keeps disagreement, age and evidence details with each reading. Old conflicting readings remain visibly conflicted. An age limit can withhold their values without hiding why they disagree.

Historical answers now choose the latest eligible observation even when the accompanying history page is short. If readings disagree at the requested time, no single value is selected. Freshness is checked at that time, and repeated reads do not change the source revision by themselves. Basic Agent history answers now include the correct supporting observation references.

What to test

  • Inspect local context — focus on the isolated qualification checks, historical page limits, old conflicts and evidence access.
  • Ask the home — check that a history answer includes actual supporting observation references.

Updated guidance

  • Read uncertain and historical context
  • Ask the home with the Basic Agent
