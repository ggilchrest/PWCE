Assistant event connections respect current access

Your Assistant's event connection now preserves its audience and identity scope, closes when access expires or changes, and requests a fresh read when replay is incomplete. A quiet connection also closes on expiry.

These checks prevent a previously opened connection from continuing to carry context after its authority changes. Full Lifestream runtime cache and provider wiring remain in progress.

What to test

Inspect local context QA — run the scoped event regression and separate Assistant process checks. Check denied identities, quiet expiry, revocation, replay handoff and incomplete replay.

Updated guidance

Keep an Assistant event connection within its scope.
