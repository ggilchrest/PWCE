Gateway authentication binding

An external Assistant must authenticate through its connection header. Request data can no longer replace that authentication.

Send the access token in the bearer header, and keep it out of the JSON body. Malformed requests are rejected before an operation starts. Knowing an authority reference still does not grant access.

Test this change

  • Inspect local context and request a safe action — focus on the external Assistant authentication check, including wrong headers, body tokens and malformed bodies.
