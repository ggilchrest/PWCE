Local Studio and HTTP control surface

You can now inspect local Home Assistant evidence and prepare a reversible action through PWCE Studio or its local HTTP API.

What changed

  • PWCE Studio shows runtime health, current state, evidence quality, observation history, and the controlled light-action boundary.
  • The approval flow can be requested and approved from Studio; live dispatch remains separately protected.
  • The local API exposes health, context, capabilities, preview, approval, dispatch, and action-status routes.
  • Live effects stay disabled unless you explicitly enable them in the development environment.

Why it matters

You can see what PWCE knows before you act. Unknown, offline, approval-required, and unreconciled outcomes remain visible instead of being presented as success.

What to test

  • QA: Inspect local context and request a safe action — focus on the evidence details, preview decision, in-Studio approval, and fail-closed live route.

Where to read more

  • Inspect local context and request a safe action — full Studio walkthrough.

Known issues / follow-ups
