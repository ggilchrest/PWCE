Studio evidence explanation

PWCE Studio now explains why a displayed state is known, stale, or unknown.

What changed

  • Select Explain current state to see the source, observation time, evidence reference, and freshness limitation behind the displayed value.
  • The explanation is read-only and does not create or change World state.

Why it matters

You can inspect the basis and limitations of a value instead of treating the current projection as unquestioned truth.

What to test

  • QA: Inspect local context and request a safe action — focus on the “Why?” result for fresh, stale, and missing evidence.

Where to read more

  • Inspect local context and request a safe action — updated walkthrough.
