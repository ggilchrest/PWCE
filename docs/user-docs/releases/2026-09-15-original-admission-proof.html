Keep the original action permission proof

What changed

Trusted integrations now receive a stable proof of the exact action PWCE admitted. It preserves the original target, arguments, approval terms, capability list and deadline. The proof stays the same after the action finishes or its result becomes uncertain.

Why it matters

You can distinguish the original permission from later action results without treating either as permission to send another command.

What to test

  • Inspect local context and request a safe action — run the original admission proof checks for stable records, exact bytes and rejection of corrupt evidence.

Where to read more

  • Inspect local context and request a safe action — check the original action permission.

Screenshots updated

None; Studio controls and layout are unchanged.

Known issues / follow-ups

The full Lifestream admission and invocation mapping remains in progress. This proof does not confirm a physical effect or renew an expired permission. Saved services and live configuration were not changed.
