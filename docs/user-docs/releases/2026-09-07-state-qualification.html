Qualified current state labels

Studio now distinguishes Known, Stale, Conflicted, and Unknown current context. This makes old or disagreeing evidence visible instead of presenting it as a current fact.

What to test

  • Follow the Inspect local context and request a safe action QA script.
  • Focus on the current-state label after a freshness window expires or sources disagree at the same event time.
