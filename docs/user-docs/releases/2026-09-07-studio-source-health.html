Home Assistant source health

PWCE now records explicit Home Assistant source health transitions instead of leaving a connected source at a generic configured state.

What changed

  • The source reports connecting, online, degraded, and offline reasons through the local health response.
  • WebSocket closure and adapter shutdown are visible as offline transitions.

Why it matters

You can tell whether a source is configured, connected, degraded, or offline before relying on its current state.

What to test

  • QA: Inspect local context and request a safe action — focus on the runtime and source-health cards.

Where to read more

  • Inspect local context and request a safe action — runtime troubleshooting.

Screenshots updated

  • No new screenshot; the existing Studio overview remains the visual baseline.

Known issues / follow-ups

  • Reconnect/backoff policy for a dropped WebSocket remains later runtime-hardening work.
