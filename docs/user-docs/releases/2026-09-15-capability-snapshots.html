Keep actions tied to current capability lists

What changed

The Gateway now retains the capability list used for an action and checks it again before dispatch. Old, foreign or invalidated lists cannot be silently replaced. Repeating an interrupted request reads its earlier disposition without restarting its action.

Why it matters

A reviewed list cannot quietly change meaning while an action waits to start.

What to test

  • Inspect local context QA — focus on stable references, scope changes, admission interruptions, preserved evidence and the synthetic HTTP check.

Where to read more

Keep an action tied to the reviewed capability list.

Screenshots updated

No screen layout changed. Existing screenshots remain applicable.

Known issues / follow-ups

Full Assistant integration, physical target preconditions and Gateway-scoped approval remain in progress. The saved services and live-effect settings were not changed.
