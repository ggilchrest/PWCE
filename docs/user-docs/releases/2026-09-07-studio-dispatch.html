Studio approved-action dispatch

Studio now lets you dispatch an Action after its request has been previewed and approved. The result shows the persisted Action status, including denied and uncertain outcomes.

What to test

  • Follow the Inspect local context and request a safe action QA script.
  • Focus on the separate Dispatch approved action step and confirm that a disabled live route is reported as denied.
