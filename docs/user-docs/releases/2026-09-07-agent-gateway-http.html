Agent Gateway HTTP binding

PWCE now exposes a development HTTP binding for the Agent Gateway. An authenticated workload can discover the selected profile, request a short-lived site-scoped authority context, and submit a gateway request. Studio’s browser session and Home Assistant credentials remain separate.

What to test

  • The transport binding is covered by automated tests in the development workspace.
  • Set PWCE_GATEWAY_TOKEN only in the ignored local environment when exercising the Agent transport.

Current limit

The development binding includes bounded operation discovery and invalidation replay. Effect requests still use the governed Action path: grant changes are rechecked before dispatch, and failed, timed-out, denied, or uncertain results stay visible. The final generated schemas, exact wire artifacts, and Lifestream compatibility lock remain deferred until they are defined.
