Live Home Assistant updates in Studio

When Home Assistant is configured, PWCE Studio can keep its local evidence current through the real state-change stream.

What changed

  • Studio still performs a startup state read, then listens for Home Assistant state changes.
  • Incoming events are normalized and admitted through the existing observation path.
  • The adapter closes with the Studio server instead of leaving a background connection behind.

Why it matters

The screen can reflect new Home Assistant state without treating a browser refresh as the source of truth.

What to test

  • QA: Inspect local context and request a safe action — focus on runtime status, current evidence, and stale or updated values.

Where to read more

  • Inspect local context and request a safe action — local runtime setup.

Screenshots updated

  • No new screenshot; the existing Studio overview remains the visual baseline.

Known issues / follow-ups

  • Reconnect/backoff policy for a dropped WebSocket is still later runtime-hardening work.
