Approval status visibility

Studio and authorized local clients can now read an approval by reference and see whether it is pending, approved, or expired.

Why it matters

You can verify the approval state before dispatch. Expired requests are made visible and remain unable to authorize an action.

Test this change

  • Inspect local context and request a safe action — focus on requesting an approval, reading GET /api/approvals/<approvalRef>, observing expiry, and confirming dispatch remains separately protected.
