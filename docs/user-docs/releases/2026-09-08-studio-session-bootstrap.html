Local Studio Human sign-in

Studio can now protect the browser with a local username and password. You can also sign in with an offline recovery code; each recovery code is accepted once and is stored only as a digest. Signing out revokes the browser session.

What to test

  • Inspect local context and request a safe action — verify password sign-in, one-time recovery, sign out, and the existing Studio journey.
