Protected Studio session bootstrap

When you configure PWCE_STUDIO_TOKEN, Studio now requires the matching bearer token before it creates a browser session. This prevents an unauthenticated caller from obtaining a session that can inspect local data or request actions.

What to test

  • Inspect local context and request a safe action — verify that an unauthenticated session request is rejected and a matching bearer token creates the session.

Documentation updated

  • Updated the inspect-local-context QA preconditions, edge cases, and change history.
  • No screenshots changed; the behavior is an HTTP bootstrap response before the Studio page loads.
