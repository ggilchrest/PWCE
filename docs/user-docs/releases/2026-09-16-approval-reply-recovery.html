Recover an approval reply

What changed

Trusted integrations can recover the original approval request after a lost reply. The record keeps the exact review, deadline and recorded Human decision.

Why it matters

You can check what happened without creating another request or accidentally approving or sending an action. A missing record stays uncertain, and an expired deadline is never extended.

What to test

  • Inspect local context and request a safe action — focus on the approval-reply recovery integration check, including changed scope and storage reopening.

Where to read more

Inspect local context and request a safe action explains how recovery differs from approval.

Screenshots updated

None. Studio controls and layout are unchanged.

Known follow-ups

The Lifestream approval controls are still being connected. Saved services and live configuration are unchanged; this release does not record new Human acceptance.
