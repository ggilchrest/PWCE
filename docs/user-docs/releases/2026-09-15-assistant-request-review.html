Review Assistant action requests

What changed

Studio now has a separate panel for pending Assistant actions. Each request has an identifier, a status and labeled fields for its target, effect and audience. You approve after signing in with your password or recovery code. Approval does not send the action.

Requests stay within the selected site, with five per page. Phone layouts wrap cleanly, and reloading preserves your valid Human session.

Why it matters

You can inspect exactly what you are approving, while the requesting Assistant must separately resume the same action.

What to test

  • Inspect local context QA — focus on exact fields, separate approval and dispatch, expiry, keyboard use, phone layout and sign-out.
