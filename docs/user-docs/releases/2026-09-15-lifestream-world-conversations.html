World context in Lifestream conversations

Lifestream can now include PWCE observations in ordinary conversations when you explicitly configure the connection and declare the session audience. Conflicting readings and old evidence keep their qualifications. Changing the audience stops a reply based on the old scope.

The connection check now exercises an actual authenticated conversation using temporary services. World information remains separate from permission to act. PWCE action administration in Lifestream is still unavailable.
