Home Assistant reconnect behavior

If the Home Assistant live connection drops, Studio now shows a degraded or offline status and retries the connection with bounded exponential backoff. This keeps the evidence view honest while giving a temporary development outage a chance to recover automatically.

What to test

  • Inspect local context and request a safe action: focus on runtime status during a Home Assistant interruption and verify that Studio does not claim live connectivity before the connection returns.

Configuration

Development defaults are an initial one-second delay, a thirty-second maximum delay, and ten attempts. Set PWCE_HA_RECONNECT_INITIAL_MS, PWCE_HA_RECONNECT_MAX_MS, or PWCE_HA_RECONNECT_MAX_ATTEMPTS in the local environment when testing another policy. A value of 0 for maximum attempts means unlimited retries.
