Site-qualified Studio inspection

PWCE Studio now lets you choose which authorized Home Assistant site you are inspecting.

Why it matters

Two sites can contain entities with the same name. The selected site is now carried through current context, history, explanations, Agent questions, and action requests so PWCE does not silently combine them. When more than one site is authorized, “All authorized sites” provides a read-only comparison with one value per site; it never merges values or authorizes an aggregate action.

What to test

  • QA: Inspect local context and request a safe action — focus on the “Home site” selector and verify that changing it refreshes site-qualified evidence and history.
