Capability change notifications

What changed

Connected integrations now receive a notification when PWCE detects that provider settings or capability definitions have changed. Each authorized site connection receives it, and reconnecting can retrieve the same notification from recent history.

Why it matters

An integration can discard an outdated capability list promptly instead of missing the change.

What to test

  • QA: Inspect local context — check live delivery, separate principals, replay, restart and revoked access.

Where to read more

  • Receive changes to a capability list — what the notification means and when a fresh read is required.

Screenshots updated

None. No Studio screen changed.

Known issues / follow-ups

The development record keeps the remaining Lifestream host integration separate. Saved services and live device settings have not changed.
