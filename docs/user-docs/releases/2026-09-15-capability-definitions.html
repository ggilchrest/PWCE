Read exact capability definitions

What changed

The light capability now provides a title, description and exact input/result definitions. An integration can retrieve the original schema bytes and verify their digest before using them.

Why it matters

The Assistant can use PWCE's actual definitions instead of inventing its own description of valid inputs or results.

What to test

  • Inspect local context and request a safe action — run the new capability definition checks for exact bytes, invalid brightness and uncertain results.

Where to read more

  • Inspect local context and request a safe action — read a capability's definition.

Screenshots updated

None; existing Studio controls and layouts are unchanged.

Known issues / follow-ups

The full Lifestream action mapping and configured workflow remain in progress. Reading a definition does not grant permission, confirm target availability or establish an effect. No saved deployment was changed.
