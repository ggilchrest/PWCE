Local Basic Agent

Studio now includes a local read-only Basic Agent. It answers current-state and recent-history questions through the authenticated gateway and shows supporting evidence references.

What to test

  • Follow the Ask the home with the local Basic Agent QA script.
  • Focus on the explicit unknown state when no accepted observation exists.
  • Confirm the Agent cannot approve or dispatch an effect.
